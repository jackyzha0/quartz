# Thrust 1: Measuring Phrasing Brittleness

> Goal: Build rigorous methods to measure when models exhibit phrasing sensitivity in medical VQA.

## Why This Matters

Medical VLMs can produce inconsistent answers when questions are rephrased, even when visual attention remains stable. This creates clinical safety concerns that need to be systematically measured.

## Dataset Development

A curated benchmark dataset for evaluating phrasing robustness in chest X-ray VQA, with:
- Multiple clinical question categories
- Expert-validated paraphrases per question
- Linguistic phenomenon annotations

## Evaluation Framework

Standardized metrics and evaluation protocols for assessing:
- Answer consistency across paraphrases
- Attention stability measurement
- Phenomenon-specific analysis

## Deliverables

- Benchmark dataset with annotation schema
- Reproducible evaluation code
- Analysis visualizations
