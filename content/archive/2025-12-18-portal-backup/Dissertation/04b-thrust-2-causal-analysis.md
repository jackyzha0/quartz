# Thrust 2: Causal Analysis

> Goal: Localize which model components cause phrasing-driven answer changes while visual focus remains stable.

## Core Idea

Treat the VLM as a causal system where paraphrases act as interventions on the text stream. Analyze how effects propagate through text encoding, cross-modal fusion, and decoding pathways.

## Methods

- Structural causal modeling of VLM components
- Activation patching experiments
- Token-level importance analysis
- Mediation analysis of answer changes

## Expected Outputs

- Component attribution analysis
- Identification of causal pathways
- Validation of mechanistic hypotheses
