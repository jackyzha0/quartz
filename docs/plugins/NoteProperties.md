The NoteProperties plugin renders a note's frontmatter properties in a collapsible panel before the page body. Its options and the per-note overrides are documented under [[Frontmatter#Properties panel plugin (note-properties)|Frontmatter]].

> [!note]
> For information on how to add, remove or configure plugins, see the [[configuration#Plugins|Configuration]] page.

## API

- Category: Transformer, Component
- Function name: `ExternalPlugin.NoteProperties()`.
- Source: [`quartz-community/note-properties`](https://github.com/quartz-community/note-properties)
- Install: `npx quartz plugin add @quartz-community/note-properties` (included in the default configuration)
